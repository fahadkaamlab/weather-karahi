# Karachi Weather App

A lightweight weather app for **Karachi, Pakistan** showing current conditions and a 7-day forecast.

## Run locally

Because this is a static app, you can run it with any web server.

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Data source

Weather data is fetched from the Open-Meteo API.
